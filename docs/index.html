Game Overview

JZBlock is a top-down zombie survival game where precision meets chaos. Armed with cutting-edge laser weaponry, you'll face relentless waves of undead enemies in a block-based world. Version 0.5 is a complete rewrite featuring dual implementations in both Zig (with Raylib) and Java (with Swing/AWT), giving you the choice between blazing-fast native performance and cross-platform portability.

Dual Language Architecture

JZBlock v0.5 features a complete rewrite with dual language support. The game now runs on both Zig with Raylib (for native performance) and Java with Swing/AWT (for JVM compatibility). The original pure Java implementation has been archived at src/main/archived/ while the new modular system takes center stage.

⚡ Zig Implementation

  • Raylib graphics framework - Modern & lightweight
  • High-performance native execution
  • Zero-cost abstractions
  • Manual memory management
  • Compile-time optimizations
  • Direct system access
  • Located: src/main/zig/

☕ Java Implementation

  • Swing/AWT windowing - Classic & reliable
  • Cross-platform JVM runtime
  • Automatic memory management
  • Mature ecosystem
  • Easy debugging
  • Familiar Java tooling
  • Located: src/main/java/

Build & Run Instructions

Choose your language and platform with the interactive build scripts:

Windows Build:

Navigate to scripts/ and run winbuild.bat (interactive menu)

cd scripts
winbuild.bat

Linux Build:

Navigate to scripts/ and run lxbuild.sh (interactive menu)

cd scripts
chmod +x lxbuild.sh
./lxbuild.sh

Archived Pure Java Version:

Original complete game available in scripts/archived/

cd scripts/archived
winbuild.bat / lxbuild.sh

Requirements:

Java Development Kit (JDK) 8+ (for Java build)
Zig Compiler + Raylib (for Zig build)

Why Dual Languages?

🚀 Raw Performance

Zig compiles to native machine code with zero runtime overhead. Combined with Raylib's efficient rendering, you get maximum frame rates and minimal latency—perfect for fast-paced zombie action.

🌐 Universal Access

Java's "write once, run anywhere" philosophy means the game works on any platform with a JVM—no recompilation needed. Ideal for quick testing and broad distribution.

🎓 Learning Lab

Comparing two implementations side-by-side teaches valuable lessons about language design, memory management, and graphics APIs. Great for students and curious developers.
